Précise combien de kcal tu veux pour ce repas — l'IA te propose plusieurs recettes calibrées. La capture Yazio est facultative : sans elle, l'IA se base sur les kcal indiquées et tes objectifs journaliers actuels.

Envoie un screen qui montre toutes tes pesées de la semaine (graphique de ton appli). L'IA calcule ta moyenne, l'enregistre avec la date, et la compare automatiquement à la dernière moyenne enregistrée pour te dire si tu dois changer de palier.

⚙️ Clé API Claude

Nécessaire pour le générateur de recettes et le bilan de poids (lecture des captures d'écran). Ta clé est stockée uniquement dans le stockage local de ton téléphone — elle n'est jamais publiée sur GitHub ni envoyée ailleurs qu'à l'API Anthropic.

Pour obtenir une clé : va sur console.anthropic.com → API Keys → Create Key. Cette clé donne accès à ton compte de facturation Anthropic : ne la partage jamais, et ne l'écris jamais en dur dans le code du site (elle serait visible publiquement sur GitHub Pages). Ici, elle reste uniquement sur cet appareil.
